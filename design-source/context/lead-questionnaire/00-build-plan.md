## Route & data (done)
- `app/leads/[id]/[tab]/page.tsx` → `tab === 'questionnaire'` renders `LeadOverview` (frame, `wide`) with body = `LeadQuestionnaire` (client). Loader `lib/leads/questions.ts` → `fetchLeadQuestions(leadId)`: `{ questions: Question[] (sortOrder), leadName, now }`.
- Schema (migration 0010): `questions` (text, type text|number|single|multi|date, options JSON, answer (multi = JSON string[], date = d/m/yyyy input string), answeredBy studio|client, answeredAt, sortOrder). Seed `scripts/seed-questions.ts` (Olivia: 11 questions, 7 answered by the studio). The Overview card now derives its counts from these rows (`lib/leads/detail.ts`).
- Model `lib/leads/question-model.ts`: `QUESTION_TYPES`, `QUESTION_TYPE_LABELS` (Text · Number · Single select (yes/no) · Multi select · Date), `parseOptions`, `parseMulti`, `answerText`, `summarise`, `validateAnswer(type, value)` (MSG from lib/forms.ts). `relativeTime` in lib/format.ts ("1d ago").
- Actions `app/leads/questions-actions.ts`: `createQuestion(leadId, text, type, options)` · `answerQuestion(id, answer: string | string[])` (always "By Studio") · `deleteQuestion(id)`.

## Rules
- Copy verbatim from the specs; the answered timestamp is `relativeTime(answeredAt, new Date(now))`; "By Client" answers are read-only (no edit icon).
- Menus / pickers toggle on their own trigger (REG-153); every icon-only control has a Tooltip (REG-75); dates only via the picker (REG-119); numbers digits-only (REG-150).
- CSS modules on `--om-*` tokens only; inside strokes as `box-shadow: inset 0 0 0 1px`; TS strict + `noUncheckedIndexedAccess`; react-hooks strict (render-phase adjust, no setState in effects).
