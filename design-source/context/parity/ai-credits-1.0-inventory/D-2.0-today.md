## Headline facts
- **2.0 never calls an AI model.** Every "AI" action is one of four kinds:
  - **REAL-LOCAL**: deterministic code that works on the real input.
  - **CURATED**: real only for curated inputs — the 3 reference quotes matched by file name, or the 3 sample rooms with their pre-rendered looks and plate.
  - **SCRIPTED**: fixed output whatever the input.
  - **COMING SOON**: the press shows the snackbar "Coming soon in OpenMaison 2.0".
- **Nothing about plans, credits or usage exists** in the schema, the UI or the register. The rail's **Upgrade** item shows the Coming-soon snackbar.
- **The AI Visualizer editor has no rail.** It lives in the `(editor)` route group, which has no rail, no Upgrade item, no studio block and no bell. That is exactly where Generate lives.
- **"Credits" is already used in the UI for Qanvast lead credits** — a naming collision (details in §5).
- **1.0 had no credits for signed-in studios.**
  - The only counter was the anonymous `/try-visualizer` trial: `TRIAL_LIMIT = 3`, only successful generations counted, with the words *"{n} of {limit} free renders left"* and *"No free renders left"*.
  - 1.0's onboarding script claims *"every render costs credits"*, *"~50 renders/month standard, 500 Pro"* and *"daily cap per studio / per-role limits in Settings → AI"*. The audit notes: "no credits/quota exist for signed-in studios" (`design-source/context/parity/ai-visualizer-1.0-inventory/A-ways-in-and-around.md:775`).
  - 1.0's Quote X-Ray had "No plan gate, trial, credit or quota" and no rate limit. One X-Ray run was a Gemini parse + match + extraction + phrasing pass, plus up to 3 web scans ("~1¢" each), all on one OpenRouter key with "no cost is attributed to a studio or member" (`…/quote-x-ray-1.0-inventory/C-around-the-xray.md:320-344`).
