## Template lifecycle

### E-11 · The template record: Draft → Published vN → Default
- Status: built
- Where: `lib/db/schema.ts` (`quoteTemplates`, `quoteTemplateVersions`), `lib/templates/model.ts` (`TEMPLATE_STATUSES`, `TemplateSummary`, `TemplateRecord`, `parseDesign`, `parseDefaults`), `lib/templates/queries.ts` (`fetchTemplate`, `fetchTemplateEditor`)
- REG: REG-485, REG-501, REG-502
- Does: a template = a DESIGN (page · brand overrides · blocks) + DEFAULTS (what a new quote starts with). Statuses `draft` · `published` (`archived` tolerated on old rows, never written). The published design and defaults live in `design_json` / `defaults_json`; the working copy in `draft_json` (`{ design, defaults }`) with `draft_updated_at`; every publish keeps a `quote_template_versions` row.
