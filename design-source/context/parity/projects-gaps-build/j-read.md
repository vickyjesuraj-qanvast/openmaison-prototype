## 1. What 1.0 does (what a studio uses)

- **Entry** (F-247…F-250): a project header button *Plan the Space (3D)* → a small dialog listing up to five of the project's layouts ("Updated
  {date}") and *Start a new 3D layout* ("Project context is pre-filled"); the same tool in the navigation as *3-D Space Planner*.
- **Starting a layout** (F-252, F-253): *My Floor Plans*; *Quick Start Templates* filtered All · HDB · Condo · Landed · Multi-Floor ·
  Pre-Furnished — HDB 3-Room (65 m²), HDB 3-Room + Balcony, HDB 4-Room (93), HDB 5-Room (110, + storeroom), Condo 2-Bedroom (65), Condo
  3-Bedroom (90, + balcony), Landed House (180, patio and garden) — each a set of **rectangular rooms placed by offset**, walls 2.6–2.8 m,
  doors and windows as fractions along a wall, a floor and a wall colour per room; draw rooms in a creator dialog; AI from a plan image or a photo.
- **The editor** (F-254, F-255, F-258): full-screen; Undo / Redo; views *Dollhouse* (3D orbit), *Cutaway*, *Top View*, *Walk* (first person);
  toggles Walls · Dims · Ruler · 2D · Furniture; *Edit Rooms* (walls, doors — single, double, sliding, pocket, bifold, opening — windows);
  a furniture catalogue (the doc says 47 items in 9 categories; the data file has grown to ~390), click-to-place with a ghost, drag, rotate,
  resize, duplicate, delete; **25 cm grid snap, 15 cm wall snap, collision checks** against walls and pieces (3 cm margin); room colours and
  textures (8 presets); keys Delete · ⌘C / V / D · ⌘Z / ⇧⌘Z / Y · arrows nudge · ⌘A · ⌘S · Esc · ?.
- **AI inside** (F-256): auto-arrange, a photoreal render, a render tour, furniture from text / a photo / a catalogue page, a fix-the-plan
  wizard. No credits charged on 1.0's branch (F-264).
- **Output and sharing** (F-257, F-259…F-262): elevations; Export PNG / PDF; *Share as 3D Link* (a random token, no expiry, *Revoke Link*
  asks first); a public viewer `/floor-plan/view/[token]` — the plan's name, "Shared floor plan · Read only", room pills that fly the camera,
  Orbit / Walk, fullscreen; manual Save (first save creates the record, each save a version with an automatic summary), localStorage every
  60 s, "Leave without saving?".

## 2. What 1.0 got wrong or never finished (not ported)

- **F-265 — a layout made from a project is never saved with it** (the create sends name + template only; the update never sets a project):
  the dialog's list stays empty, "Project context is pre-filled" is false. **2.0 stores the project (and its lead) on the layout at creation.**
- **F-266** — the project chip is fetched and never shown; Back returns to the planner's entry, not the project. **2.0 names the project in the
  editor's bar and Back goes where it came from (`?from=`).**
- **F-267** — opened from a project, *My Floor Plans* filters to that project and hides the studio's others with no message. **2.0's gallery
  always shows everything the member may see; a project's layouts carry the project's name.**
- **F-268** — three names for one tool. **2.0: the tool is the *3-D Space Planner*; its records are *layouts*.**
- **F-262** — the viewer walls off phones and portrait screens ("Rotate your device"). **2.0 designs the viewer for the phone.**
- Manual Save with crash copies and a leave warning (F-259): **2.0 saves itself** (the Visualizer's way: "Saving… · Saved"), so nothing is lost.
- A furniture list that grew to ~390 GLB-backed items, AI vendors (Meshy, generate v1–v3), a scene graph: not ported (see §4).
