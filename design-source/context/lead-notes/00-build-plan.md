## Route & data (done)
- `app/leads/[id]/[tab]/page.tsx` → `tab === 'notes'` renders `LeadOverview` (frame, `wide`) with body = `LeadNotes` (client). Loader `lib/leads/notes.ts` → `fetchLeadNotes(leadId)`: `{ notes: NoteRow[] (creation order, each with attachments: LeadFile[] + author), files: LeadFile[] (the library), team, now }`.
- Schema (migration 0009): `lead_notes` (kind note|contact, title, body, channel, contactedAt, outcome, nextStepAt, nextStepMode, authorId, createdAt, updatedAt) + `note_attachments`. Seed `scripts/seed-notes.ts` (Olivia: the mock's note with four Q-101 attachments + a "Callback requested" WhatsApp log).
- Model `lib/leads/note-model.ts`: `NoteKind`, `NoteFilter` ('all'|'note'|'contact'), `NoteDraft` (title · body · channel · when · outcome · nextStepWhen · nextStepMode — dates as input strings), `emptyDraft(kind)`, `draftFrom(note)`, `nextStepFor(outcome)`, `validateDraft(draft)` (contact rules = the Move stage window's: channel, when, outcome; next-step date + mode when the outcome has a next step), `listTitle`, `listSecondary`, `filterNotes`. Shared vocabulary in `lib/leads/enums.ts`: `CONTACT_CHANNELS`, `OUTCOMES` (Connected · Callback requested · Meeting scheduled · No response), `NEXT_STEP_BY_OUTCOME` (Connected → Schedule a meeting, Callback requested → Schedule a call), `CONTACT_MODES` (channels + In person). `lib/format.ts`: `displayDateTimeDot` ("17 Jul ’26・12:34 PM"), `displayDateTime` ("17 Jul ’26, 3:00 PM").
- Actions `app/leads/notes-actions.ts`: `createNote(leadId, draft, fileIds)` · `updateNote(id, draft)` · `deleteNote(id)` · `setNoteAttachments(id, fileIds)`. Tasks from "Add tasks": `createTask(leadId, title)` from `app/leads/tasks-actions.ts`.

## Rules
- Order = creation order; a **draft** (unsaved new note / contact log) appears as the last list item ("New" / "Contact log", "No notes yet", now) and is selected; Cancel discards it, Save persists (snackbar "Note saved" / "Contact log saved"). When the lead has **no notes at all** the tab opens with a blank note draft (frame 79). Selecting another item while a draft is dirty keeps the draft's item but asks nothing (the editors keep their state per id).
- Note editing: the editor is always live; the footer appears once the draft differs from the saved note; Save → `updateNote`; Cancel restores. Contact logs open in **view** (frame 163) and switch to editing via Edit / kebab Edit (frame 165); validation errors show after the first Save and clear live (REG-119 dates via the picker only).
- **Auto Fill** (contact log, editing): dialog → Upload → fills channel WhatsApp · When = now · Outcome Connected · next step = 3 days ahead at 7:00 PM · mode In person · body "Client confirmed the renovation scope over WhatsApp and asked for a site visit next week." (invented copy, logged), then opens **Add tasks** with auto-added `Schedule a meeting with the client for <Weekday, d Mon ’yy> at 7PM` and the suggestion "Prepare sample designs and floor plan illustrations for the client"; Save creates the ticked tasks (`createTask`) and snackbars "n tasks added"; Cancel adds none.
- Attachments: attach_file_add → `AttachFilesModal` → `setNoteAttachments` (for a draft: kept in state and sent with `createNote`); tile kebab → Remove; tile click → `/leads/<id>/files/<fileId>`.
- Menus toggle on their own trigger (REG-153); every icon-only control has a Tooltip (REG-75); inert affordances → "Coming soon in OpenMaison 2.0" (bold/italic/underline/lists, Refine).
- CSS modules on `--om-*` tokens only; TS strict + `noUncheckedIndexedAccess`; react-hooks strict (render-phase adjust for the selected/draft state; no setState in effects). Card uses `box-shadow: inset 0 0 0 1px` for the inside stroke.
