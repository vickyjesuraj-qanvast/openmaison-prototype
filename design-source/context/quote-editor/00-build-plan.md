## Decisions (owner, 2026-09-11)
- **Entry**: every "new quote" path (Quotes tab **Create Quote** — was "New Quote ▾", empty-state buttons, Overview QUOTES card, Create quick link › Quote, Won wizard › Create quote, Tools › Quote Digitizer) opens the **Create Quote modal (XL 1200 — owner 2026-09-11; design reference reviewed first)**; "Use This" / "Start blank" create the Draft and open the editor. Upload / Draft with Maison AI / View all / New design template / Preview → coming soon.
- **Route**: `/quotes/[quoteId]` — its own route group (`app/quotes/layout.tsx`, no AppShell) so the page is a full-page surface with no rail (REG-406). Header back arrow and ✕ return to the lead's Quotes tab.
- **Header**: title chevron = switch to another quote of this lead; Send moves the status one step (approval required: Draft → Sent for Approval; not required: Draft → Sent to Client), stamps Sent, snackbar, no dialog; Preview · comment · kebab items → coming soon (kebab list 1271:41512 built as a menu); autosave with "Saved n mins ago"; VERSION stays 1.
- **Sections**: General Info, Items and Activity are fixed (no handle — 1271:39681 · 1260:31210 · 1260:32316); Payment, Files, T&Cs, Notes and Signature reorder by their handle and the order + collapsed state persist per quote (REG-407); default = General Info and Items open, the rest collapsed (owner 2026-09-11); the Draft status pill stays in General Info for now (REG-404).
- **Side strip** (1271:40377): Create · Maison AI · My Items · Templates · Recent Quotes · Brand Catalog — the quick-links strip pattern (72 collapsed / 140 expanded).
- **Items**: Unit Price = Cost + Markup; line Total = Qty × Unit Price × (1 − Discount%) × (1 + GST%); Subtotal = Σ line totals before GST; Additional Discount % or S$; GST 9% toggle; Margin = (Total − ΣCost) / Total. Groups sum their children. Item status (Pending · Approved · Declined) editable. "+" inserts a row below; Add Item row + popover (My Items price book); undo / redo real; density Single / Double / Triple; View by None / Category / Room / Section (subtotal header rows, "Add Category" / "Add Section" toolbar buttons, Collapse All); hovered-row kebab (reference menu minus Create Document(s) — REG-410); bulk bar on selection; thumbnail menu Upload Image › · Use Icon › · Upload Logo; column settings panel. Issuing Entity defaults to the studio.
- **Payment**: presets (10/30/30/30 + a few + Custom); amounts = quote total × %; due dates via DatePicker; inline edit with ✓ / ✕; over-balance error; Add Payments with AI = the three loading cards → generated schedule + Undo banner ("Here's a Maison AI generated payment schedule").
- **Files**: quote files also live in the lead's Files tab; Attach files modal reused.
- **T&Cs / Notes**: in-house rich text (B I U S · lists · align · link); templates modal (empty → list; New Template with Insert Token ▾); Add appends; Write with AI derives from the quote's items.
- **Signature**: designer signature saved once per member, prefilled; toggle off does NOT hide the client block.
- **Data**: no mock data — every value from records (REG-403); seed a price book ("My Items") and realistic items behind the seven seeded quotes (invented copy, logged).
- **Responsive**: full mobile / tablet passes per phase (responsive.md rules).
