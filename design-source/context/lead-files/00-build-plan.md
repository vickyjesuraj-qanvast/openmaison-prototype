## Route & data (done)
- `app/leads/[id]/[tab]/page.tsx` → `tab === 'files'` renders `LeadOverview` (frame, `wide`) with body = `LeadFiles` (client). Loader `lib/leads/files.ts` → `fetchLeadFiles(leadId)`: `{ files: FileRow[] (every untrashed file/folder, all levels), trashed: FileRow[], team, now }`.
- Viewer route (frames 92–95): `app/leads/[id]/files/[fileId]/page.tsx` (new, `force-dynamic`, notFound on a missing/trashed/folder id) → `fetchFileView(leadId, fileId)`: `{ lead, file, folder, siblings, comments (with author), team, me, now }` → `<FileViewer data />`.
- Schema (migration 0008): `lead_files` + `parentId` (null = root) · `ownerId` · `sizeBytes` · `mime` · `updatedAt` · `deletedAt`; new `file_comments` (id, fileId, authorId, body, createdAt, updatedAt). Seed `scripts/seed-files.ts` (Olivia: 12 JPEGs "Q-101" 711 KB by James, four inside "Kitchen", one comment on the first).
- Model `lib/leads/file-model.ts`: `FileRow` (= LeadFile + owner · commentCount · attachedTo 'Task'|null · itemCount), `isFolder`, `fileTypeLabel`, `childrenOf(files, parentId)`, `descendantIds`, `folderPath`, `groupByDay` (→ `{ day, label "Friday, 17 Jul ’26", files }[]`), `searchFiles`. `lib/format.ts`: `displayDateWeekday`, `fileSize` ("711 KB").
- Actions `app/leads/files-actions.ts`: `createFolder(leadId, name, parentId)` · `uploadFile(leadId, parentId, name?)` (REG-149: the picked file becomes the mock's "Living Room" JPEG) · `renameFile(id, name)` · `moveFiles(ids, parentId|null)` · `duplicateFiles(ids)` · `trashFiles(ids)` · `restoreFiles(ids)` · `deleteFilesForever(ids)` · `emptyFileTrash(leadId)` · `addFileComment` / `editFileComment` / `deleteFileComment`.

## Rules
- Menus toggle on their own trigger (REG-153); every icon-only control has a Tooltip (REG-75); inert affordances → "Coming soon in OpenMaison 2.0".
- Copy from the mocks verbatim (01–04). Selected surfaces = primary-variant fill. Group/head checkboxes: DS Checkbox with `isIndeterminate`.
- Tables are one CSS grid with subgrid rows (REG-180). Cards/tables use `box-shadow: inset 0 0 0 1px` for Figma's inside strokes.
- CSS modules on `--om-*` tokens only (no `--om-spacing-7`); TS strict + `noUncheckedIndexedAccess`; react-hooks strict (no Date.now()/refs in render except lazy initialisers, no setState in effect bodies — render-phase adjust pattern).
- The trashed set reaches the sheet from `data.trashed`; Restore/Delete Forever/Empty Trash refresh via `router.refresh()`.
