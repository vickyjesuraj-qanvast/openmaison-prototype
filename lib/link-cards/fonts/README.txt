These two files are static instances (400 Regular, 600 SemiBold) from Google Fonts, subset to Latin with fontTools
(pending modules S02, 2026-10-11). They draw the picture card a client link shows when it is pasted into WhatsApp
(lib/link-cards/card-image.tsx) — the app's own type, which the card's renderer (next/og) cannot read as woff2.
