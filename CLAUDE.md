## How we work (non-negotiable)

1. **The mock wins.** Never invent UI, copy or data. If something is not in a mock, propose first; when the user says build it anyway, log it in `design-source/REGISTER.md` (REG-nnn: what, why, source — `mock` / `user-directed` / `invented copy` / `bug fix`). The register is the audit trail the client sees.
2. **Verify every change visually** with Playwright at 1440×1024 against a production build on **:3011** (`npx next build && npx next start -p 3011`), screenshots into the scratchpad, then bank the meaningful ones under `design-source/verify/`. **Stop :3011 when done.** The user runs their own `next dev` on **:3000** — never touch it; when they report something you can't reproduce, check their :3000 too.
3. **DB safety.** `local.db` is the demo data. Tests must leave it as found (diff `leads` stages / `stage_logs` counts before and after); revert any test mutation. Don't seed or reset unless asked.
4. **Generic pieces everywhere.** Every screen ships the shell (rail, page header, ghost loader `loading.tsx` + `PageReveal`, tooltips, snackbar host, Maison AI FAB — the FAB and its sheet come with `AppShell`, REG-507; a page with scripted suggestions registers them with `useMaisonAi`). Reuse `components/om/*`; never hand-roll an input, menu, dialog or picker. Checklist: `design-source/context/page-checklist.md`.
5. **Remember rules.** When the user says "remember this", it goes into the register, the checklist and the memory directory (`~/.claude/projects/-Users-livspace-Documents-GitHub-openmaison-prototype/memory/`).
6. Keep review workflows compact (the user dislikes long waits). Commit only when the user says so.

## Stack & conventions

- Next 16 App Router (Turbopack), React 19, TS strict + `noUncheckedIndexedAccess`, ESLint react-hooks strict (no `Date.now()`/refs read in render; no setState in effect bodies; use the render-phase adjust pattern or lazy `useState` initialisers), `motion` with `lib/motion` tokens, CSS modules on `--om-*` tokens.
- Data: Drizzle + libSQL `local.db`. Schema `lib/db/schema.ts`; migrations `npm run db:generate` → `npm run db:migrate` (additive only). Server actions in `app/leads/actions.ts` (+ `app/settings/actions.ts`) with `revalidatePath`.
- Radii: 4 fields/buttons · 8 cards · 12 modals. Elevation `--om-elevation-level-1…5`. Type tokens `--om-type-*`.
- Modal scale: **s 400 · m 600 · l 800 · xl 1200** (`--om-modal-*`), height to content (viewport-capped); **xxl = fluid, 48px margin on every side**. Modal header standard (779-26016): 64px, 20/24 padding, 20px bold title, bare 24px close icon, 1px divider. No full-page overlays.
- Switches: always the DS `sm` size (REG-460).
- Snackbar: 344×48, radius 4; action = DS text button in `#CCB2FF`; every inert affordance answers "Coming soon in OpenMaison 2.0".

## Product rules decided so far (all logged in REGISTER.md)

**Stage movement** (Settings › Leads, `settings` table, REG-111…): Linear (default) = one stage at a time, next stage only; Flexible = instant moves with Undo. Won always opens its step (creates the project). On Hold / Lost keep compact dialogs (On Hold: 1 / 3 / 6 month · Custom chips, Custom alone reveals the "Follow up on" date, REG-453). **Nothing moves backwards** — a completed stage opens read-only in the Move stage window with Edit; kanban drops on earlier columns spring back. Parked leads resume anywhere with a "Resume at X?" confirm. **A lead needs an owner before it leaves New** ("Assign a member first"); past New the Assign popover refuses an empty selection. **Convert to Project** opens the Move stage window at Won where the policy allows, else the lock stays and the press says why (REG-469). **A quote's due date raises a follow-up task** on the lead, kept in step with the date (REG-470); quotes carry a Creator column (REG-471). **Quote templates** (REG-485…493): a template = design + defaults, Draft → Published vN → Default, sent quotes pinned to their version, open drafts get a banner; the client sees only client-facing content exactly as Preview shows; cost and markup never print; an Optional mark keeps a line out of the totals (REG-492). **Template approval** (REG-501, Settings › Leads): Owners / Admins publish, Designers submit with a note; the owner approves in the editor's review bar or requests changes; awaiting = a submission on the record, not a status (a published template keeps printing while its change waits). **Templates delete softly** (REG-502): `deleted_at`, Deleted templates in the gallery's kebab, Restore / Delete forever (never while a quote prints through it); no Archive.

**Move stage window** (`components/leads/move-stage/*`): Contacted and Met are **log lists** (Add Log in the title row; each log card = "Log n" · Auto Fill · delete (when >1) · chevron; dividers between field block / attachments / notes). **Read-only is per log**: completed logs stay locked until their own Edit; Add Log opens only the new log. Quote Sent / Won use a whole-stage Edit. New (assignees) is editable inside the window only while the lead is still in New — Save assigns the ticked members, and New is checked in the rail only once it has one (REG-334); past New it stays read-only. Every field except notes and the optional schedule pair (REG-319) is mandatory; validation in `lib/leads/stage-data.ts` (`validateStage`), messages in `lib/forms.ts`. **Contacted journey:** fill (manually or Auto Fill → upload) → Save → *Suggested tasks* → Save adds the ticked tasks (persisted in `lead_tasks`, surfaced later in Lead Details › Tasks) and completes the move; Cancel completes it without tasks. **Upload flow** (Quote Sent / Won, 780:90940 → 91263 → 91468, 780:92744): any picked file → "Uploading..." → the mock's file row under the dropzone; Quote amount (S$) only in the upload flow; the Won payment split follows the signed quote's source — uploaded file zeroes it, back to a system quote restores 10/30/30/30 (REG-149).

**Fields** (`components/om/text-field.tsx`, `date-field.tsx`): one `TextField` for everything — Material label-inside-when-empty, DS states from mocks 836-23125 / 836-23276 (empty · active 2px · filled · error red + 12px message · disabled). Number fields (amounts, phone, area, %) use `numeric="digits"|"amount"` — junk is filtered as typed, never merely flagged (REG-150). Phone boxes show the digits grouped as typed, "9123 4567" (`phoneTyped`), and hold the bare 8 digits (REG-456). Dates are never typed: `DateField` / `DateTimeField` open the Material picker (time row + Today are invented, REG-119/125). Errors show after the first submit and clear live. **Filter modals and the Column settings drawer apply live** — each change reaches the list at once, the primary button is Done (REG-464, `components/om/use-live-apply.ts`).

**Listing**: the primary left band = a **new lead nobody has seen or clicked yet** (`seen_at` null; clears on first click). "Return Lead" only for Qanvast-sourced leads. Anchored popovers (stage dropdown, tasks, assign) follow their cell on scroll and close when it leaves the viewport; dropdown menus close on any press outside the menu. **Back returns where you came from** (REG-465, `lib/nav.ts`): a link from a list to a record carries `?from=<list URL>`; the quote editor's close, the lead's L2 Back (crumb "{section} / Leads") and the file viewer's Back honour it. **Frozen columns**: 1px inner border at rest, shadow only while scrolled sideways. **Column settings** (REG-454): every list table shares one drawer (`components/om/column-settings.tsx`, `tune` button after Filters; order · visibility · up to 3 pinned, per browser in `om.columns.<table>`; declare columns once, `useTableColumns` + `useColumnLayout` in `components/om/table-columns.ts`).

**Review imported leads**: xxl modal; source chips count what the toggle shows; queue duplicates show the row they collided with (same file or an earlier import) side by side; merge table = single-line rows, label column frozen left, Merged result frozen right, equal data columns, 12px caption headers.

**Demo data must be internally consistent (REG-343)**: every state a screen shows must be backed by the records that produce it — a lead in Contacted needs its New→Contacted stage log with a contact-log payload, members need `assigned_at`, a Quote Sent lead needs its approved quote. Never seed a state "as is from the mock" without its trail. `npm run db:repair` (`scripts/repair-demo-data.ts`) writes those records idempotently and ends with its verification queries; run it after ANY seeding, then `npm run db:baseline`. When a new record type appears, add its Activity branch (`lib/leads/activity.ts`) and its repair rule together.

**Base state**: `fixtures/baseline.json` is the curated demo state; Maison AI › "Reset prototype to base" restores it (clears `om.*` localStorage, reloads). After curating data, run `npm run db:baseline` — never edit the JSON by hand.

## Icons (self-hosted subset)

Icons are the Material Symbols variable font, **self-hosted and subsetted** (REG-207): `public/fonts/material-symbols-{rounded,outlined}.subset.woff2`, declared in `app/globals.css`, preloaded in `app/layout.tsx`. `public/fonts/ICONS.txt` lists every icon name inside.

**Using an icon name that is not in that list renders the literal word.** After adding one, re-subset:

```bash
# 1. download the full fonts from the Google CSS API (see the URL in git history of app/layout.tsx)
# 2. resolve each name through the font's ligature table (names like `people_alt` are aliases → glyph `group`)
# 3. subset:  python3 -m fontTools.subset <full>.woff2 --glyphs=<resolved glyphs + .fill variants> \
#      --text=abcdefghijklmnopqrstuvwxyz_0123456789 --layout-features=liga,calt,rlig,rclt --no-layout-closure \
#      --flavor=woff2 --output-file=<out>.woff2 --no-hinting --desubroutinize --notdef-outline
# 4. verify: every `.msr`/`.mso` span must be as wide as its font-size (a missing glyph renders the whole word)
# Notes (2026-09-16): the ligatures live in `rlig`; the FILL=1 swap to an icon's `.fill` glyph lives in `rclt` FeatureVariations, so keep
# `rclt` and list every `.fill` glyph — and an icon without a `.fill` glyph or FILL deltas (e.g. `task_alt`) can never render filled;
# pick another (the rail's Tasks uses `task`). fontTools: `pip3 install --user fonttools brotli`.
```
